ARTOFTOMWORKS CREATOR HUB — 0.17.0
24 November 2026

Public update after 0.14.1. Includes all 0.15.x and 0.16 work.

- Several models at once for image and video: models × formats in one start,
  favourites/family quick-pick, a “trial” mode for video, series bar with
  pause, resume and cancel, grid view (models × seeds), optional local-AI
  model suggestion and ranking.
- Two-stage LTX 2.5 custom workflows supported. Save or reload the exact
  workflow of any History result.
- Scene continuation, next-scene assistant, storyboard with short-film export,
  character book, variation family tree, “Same, but…” buttons, morning picks.
- Ideas box (Alt+I) with images, tags and one-click prompts.
- Sound plan for audio-capable video models (LTX 2.5, MiniMax H3) and a sound
  tool for finished videos (fades, levelling to −16 LUFS, music with ducking).
- Start image guard, also for “Several models at once”.
- Camera capture (mirror, countdown, three shots) for start images and styles.
- Themes, background images and a comfortable zoom.
- Privacy switch (Ctrl+Alt+H) that blurs all media.
- Optional profiles with passwords and per-profile data; optional parental
  controls (allowed models, LoRA/assistant permissions, word filter).
- Civitai/Hugging Face model search improvements, model thumbnails,
  encrypted remembered model-source keys (Windows DPAPI).
- Out-of-memory self-healing, automatic memory release on model change,
  windowless server with tray icon, ⏻ Hub menu (restart, stop, log).
- Companion LTX 2.5 workflows (Draft → Final, Simple; EN and HU) in the
  workflows folder.
- Fixes: removing a start image no longer leaves an automatic plan demanding
  one; image generation without a start image always uses full denoise;
  queue removal removes only the selected plan; draft saving is robust against
  Windows file locks; many interface and translation fixes in all eight
  languages.

Not tested in this release: real webcam capture on Windows, profile mode and
parental controls on the release machine, and real GPU generation quality
for every model family. See VALIDATION_EN.txt.
