# Singularity 0.17.1 — validation

## Clean start

- Windows launcher check passed with bundled Node.js v24.19.0.
- An isolated loopback server using the Windows package files reported 0.17.1, served an English first-start setting and returned empty History and draft. Main UI, New labels, creative advice, grid and English locale routes responded.
- The Node.exe SHA256 was compared with the bundled upstream Windows x64 checksums.
- No live ComfyUI generation, Ollama inference or end-to-end browser workflow was run on the staged release.
- Video segment replacement uses a separate clip and an editable splice. Full-motion/audio evaluation and native Retake are outside this release.

## Test suite

386 passed, 3 failed, 2 skipped out of 391 tests in the staged source snapshot.

- Two older assertions expect conflicting model metadata or an incomplete H3 LoRA signature to produce no family match. The current detector returns a family in those cases and records metadata mismatch where applicable. Model/LoRA identification in these edge cases requires review before a stable release.
- New strings passed the English coverage check. The seven-language check still flags missing native translations for newer controls in the other locale packs, where the interface can fall back to English.

## Privacy and integrity

The application archive was rebuilt from the previous public file list and explicitly selected runtime modules and dictionaries. The source archive includes public tests and synthetic/test fixtures. The companion archive contains public example workflows.

No application data directory, profile sessions, histories, drafts, personal model catalogue, model weights, output media, logs, credential store, developer handoff notes, or Git history are included. Known private path and credential patterns were scanned on staged text and ZIP entry names. Archive contents were re-read and SHA256-compared to staging. The cover images were generated for this release.
